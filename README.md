# Managing design tokens from Figma to production code


As a key chain of the workflow of managing design tokens, this is where we host the design token json files and the producton code translated by Style Dictionary.

The design token json files are exported from Figma by using the plugin **[Design Token Manager](https://www.figma.com/community/plugin/1263743870981744253)** which ensures the exported json file follow the technical specificaitons of the **[Design Tokens Format Module](https://www.designtokens.org/tr/drafts/format/)**.

**[Style Dictionary](https://styledictionary.com/)** works as the translater who turns design token json files into production code by platform, e.g. iOS, Android and web.

Style Dictionary will run automatically once the json files are updated.
